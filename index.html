Desarrollo Web

HTML, CSS, JavaScript:

Son los tres pilares fundamentales del desarrollo web que trabajan juntos para crear páginas web dinámicas e interactivas. HTML se encaraga de la estructura y el contenido, CSS del diseño y la presentación, y JavaScript de la interactividad y la funcionalidad

Definiciones:

HTML (HyperText Markup Language):

Es el lenguaje de marcado que define la estructura y el contenido de una pagia web. Utilia etiquetas para delimitar diferentes elementos, como párrafos, encabezados, imagenes, etc.

CSS (Cascading Style Sheets):

Es un lenguaje de estilos que se utiliza para controlar la presentación de una página web. Permite definir aspectos, como los colores, fuentes,tamaños,márgenes, etc.

JavaScript (Program Language):

Es un lenguaje de programación que permite agregar funcionalidad interactiva a una página web. Permite manipular elemnetos HTML, responder a eventos del usuario, realizar cálculos, etc.
